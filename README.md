# Excel 图片粘贴助手

解决"从微信复制图片粘贴到 Excel 后图片巨大、还要手动调整"的问题。

## 使用方法（已升级：直接按 Ctrl+V 即可）

1. 双击 `启动.bat` 运行程序（窗口可最小化，挂在后台）。
2. 从微信（或任意程序）复制一张图片。
3. 在 Excel 中选中目标单元格，**直接按 Ctrl+V** —— 程序自动拦截，
   图片按你设定的尺寸规则插入，完成后自动跳到下一行，可连续粘贴。

> 程序会精确区分“图片”和“表格数据”：粘贴文字、数字、复制单元格或区域、
> 从 Word 等处复制文本，全都完全不受影响，正常走 Excel 原生粘贴。
> 原理：Excel 复制单元格时会在剪贴板里附带一份位图（供不支持表格的程序
> 降级使用），程序通过识别 Biff / Csv / SYLK / RTF 等表格专有格式避免误判。

也可以按备用快捷键 **Ctrl+Alt+V** 手动触发（不占用 Excel 的 Ctrl+V 时）。

## 双击图片看大图

在 Excel 里**双击任意已插入的图片**，即弹出置顶大图预览窗口：

- 小图自动放大、大图自动缩小，都适配到屏幕大小
- 预览使用图片的**原始分辨率**（插入时自动缓存原图），不是模糊的屏幕截图
- 单击、双击或按 `Esc` 关闭
- 双击时程序会吞掉第二次点击，不会弹出 Excel 自带的"设置图片格式"面板

在设置界面可关闭此功能（"双击图片弹出大图预览"复选框）。

> 稳定性说明：双击判定已按系统双击距离 + 高 DPI 缩放换算，且不要求
> 点击时 Excel 恰好是前台窗口（按点击位置所在的窗口判断）；被吞掉的
> 第二次点击也会正常计入点击序列，连续双击不会出现"时灵时不灵"。

## 图片清晰度（为什么不会被压缩）

Excel 默认会在插入/保存时按图片的**显示尺寸**自动压缩（约 220 ppi）：
一张 2400×1800 的照片插进单元格后，可能只剩一百多像素，放大就糊。

程序启动时会自动关闭这个行为
（注册表 `AutomaticPictureCompressionDefault = 0`），插入的图片始终
**保留原始分辨率**。该设置需要**重启 Excel 才生效**，启动日志里会有
一行说明：

- `Excel 图片自动压缩已处于关闭状态` —— 无需处理
- `已关闭 Excel 图片自动压缩（Office 16.0），重启 Excel 后生效` —— 关掉
  Excel 再重新打开即可

代价是工作簿体积会变大（插入手机原图时尤其明显），这是保留清晰度的
代价。如需恢复压缩：Excel → 文件 → 选项 → 高级 → 图像大小和质量。

## 三种插入模式（程序界面中切换）

| 模式 | 效果 |
|------|------|
| 自动加高行（推荐） | 图片宽度撑满列宽，行高自动加高适配图片 |
| 适应单元格 | 图片缩小到刚好放进当前单元格内 |
| 固定宽度 | 所有图片统一缩放到设定宽度，高度按比例 |

其他选项：
- **拦截 Excel 中的 Ctrl+V**：总开关，关闭后只保留备用快捷键。
- **双击图片弹出大图预览**：总开关。
- **单元格留白**：图片与单元格**四边**的空隙（磅），默认 3。
  图片不会贴着单元格边框，网格线始终露在外面。若觉得留白不够明显，
  调到 **5～8** 磅即可（范围 0～20）；想让图片更满就调小。
- **小图不放大**：适应单元格模式下，小于单元格的图片保持原尺寸。
- 插入的图片已设置"随单元格移动和调整大小"，后续调整行高列宽图片会跟着变。

## 出问题怎么排查

程序同目录下的 `log.txt` 记录了每次按键拦截、插入成功/失败的详细日志
（保留最近 200 条）。把里面的内容发给助手即可快速定位。

常见问题：
- **图片还是原样插入**：看 log.txt 是否有"触发方式：Ctrl+V 拦截"。
  没有说明程序没在运行——重新双击 `启动.bat`。
- **提示"未检测到正在运行的 Excel"**：需要先打开 Excel（支持微软 Excel
  和 WPS 表格）。
- **Excel 是管理员权限运行**：普通权限的程序连不上它，用同样方式
  （管理员）运行本程序即可。
- **复制单元格粘贴后却变成了图片**：早期版本存在此缺陷（Excel 复制单元格时
  附带位图被误判为图片），现版本已修复。若仍出现，看 log.txt 中该次按键是
  "放行"还是"拦截"，把日志发给助手即可定位。
- **图片在 Excel 里放大后模糊**：Excel 的自动压缩还开着。把 Excel 完全关闭
  再重新打开一次（程序启动时已自动写好设置）。
- **双击图片没反应**：看 log.txt 里是"已弹出预览"、"双击未预览：..."还是
  完全没有记录。完全没有记录说明点击位置没被识别为 Excel 窗口，
  确认 Excel 窗口可见、没有被其他窗口完全遮挡。

## 修改快捷键

编辑同目录下 `config.json`：

```json
{
  "hotkey_mod": "ctrl+alt",
  "hotkey_key": "v",
  "intercept_ctrl_v": true
}
```

改完在程序界面点"保存设置"重新生效。

## 安装（首次）

程序依赖 Python 3 和两个库。在程序文件夹打开命令行执行：

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

之后双击 `启动.bat` 即可（会自动使用自带的 .venv，无黑色命令行窗口）。

## 文件说明

- `main.py` —— 主程序（Python）
- `config.json` —— 运行后自动生成的配置文件
- `log.txt` —— 运行日志（自动生成，排查问题用）
- `cache/` —— 原图缓存（双击预览用，自动管理，最多保留 400 张）
- `requirements.txt` —— 依赖清单
- `启动.bat` —— 双击启动（无黑窗口）
